# CodeBrix

CodeBrix is an open-source, extensible visual programming platform for Machine Learning.

## Vision

Build machine learning workflows visually using drag-and-drop blocks.

Generate executable Python code automatically.

Execute workflows locally.

Display notebook-style outputs and interactive visualizations.

Enable community-driven visual libraries through a plugin architecture.
