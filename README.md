## 🚀 Vision

CodeBrix aims to simplify Machine Learning development through a visual, drag-and-drop programming interface while preserving the power and flexibility of Python.

With CodeBrix, users can:

- 🧩 Build machine learning workflows visually using reusable blocks.
- 🐍 Automatically generate clean, executable Python code.
- ⚡ Execute workflows locally.
- 📊 View notebook-style outputs, visualizations, and results.
- 📦 Extend the platform through community-driven libraries and plugins.
- 🛠️ Create and reuse custom blocks for their own workflows.
