# CodeBrix Block Libraries

This directory houses the block library packages for CodeBrix:
- `core/`: Variables, Conditions, Math, Logic (Developer 1)
- `data/`: CSV, JSON, Excel, Scaling, Encoding (Developer 1)
- `scikit-learn/`: Train/Test Split, Random Forest, Linear Regression, Decision Tree, KNN, Predict, Accuracy (Developer 2)
- `visualization/`: Confusion Matrix, Feature Importance, Plots (Developer 2)
